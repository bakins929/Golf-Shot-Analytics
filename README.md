# Golf-Shot-Analytics
Golf shot analytics

The HTML file contains code to visualize launch monitor data exported via CSV.  This should work with GSPro, Trackman, Flightscope, Foresight, Uneekor, and more.

Instructions:

Download the HTML file and the Demo.csv file.  Alternatively, you may use your own CSV file.
Open the HTML file with a browser of your choice.  You will see the welcome screen:

<img width="619" height="561" alt="2026-05-22 07_12_49-Golf Visualizer - File Explorer" src="https://github.com/user-attachments/assets/04235898-633e-4b36-b9e9-11fa75911758" />

You may click to navigate to your CSV file, or drag and drop it into the dashed square area.
