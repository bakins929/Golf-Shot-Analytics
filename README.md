# Golf-Shot-Analytics

The HTML file contains code to visualize launch monitor data exported via CSV. This should work with:
- GSPro
- Trackman
- Flightscope
- Foresight
- Uneekor
- and more

## Features:

- You can import almost any CSV from a launch monitor and map the columns in the very top section if it doesn't understand the format.
- Visualize all shots, or by a specific club.
- Cross-chart context, select a shot in one graph, and it is highlighted in yellow on all of them.  Other shots are dimmed. Escape to clear.
- If you hover over a shot, a pop-up displaying all the metrics for that shot will appear.
- When a shot is selected, the histogram bar with that shot is highlighted (bottom).
- Shot trajectory views for top and side (Added to v4)

## Instructions

- Download the HTML file and the Demo.csv file
  - Alternatively, you may use your own CSV file
- Open the HTML file with a browser of your choice
